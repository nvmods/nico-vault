# NicoFiles

Gestionnaire de fichiers Android personnel, sans publicité, sans compte, sans télémétrie et sans permission Internet.

La version 1.0 comprend : navigation dans le stockage interne, carte SD et USB visibles par Android ; accès complet au stockage ; liste ou grille ; tri et fichiers cachés ; recherche récursive ; sélection multiple ; copie, déplacement, renommage et suppression ; création de dossiers ; corbeille avec restauration ; ZIP et extraction ZIP ; favoris et récents ; miniatures ; partage Android ; état du stockage ; envoi direct d'un document vers NicoVault.

Le projet Android est versionné directement dans le dossier `NicoFiles/`. Le workflow `Build NicoFiles APK` compile ce dossier, lance les tests unitaires et construit l'APK debug sans dépendre d'une archive ZIP.

Artefact attendu : `NicoFiles-v1.0-debug-apk`.
